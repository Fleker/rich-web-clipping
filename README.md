# Felker Web Clipper

This tool uses Chrome's built-in on-device LLM to summarize posts from Twitter (X) and BlueSky and turn it into an informational Markdown link that is written to your clipboard.

Then it allows you to open an Obsidian vault to a specific file to paste.

This also works with Instapaper. Additional services may be added over time.

## Privacy

This extension is very minimal. The source code is published here. It does not make any changes to user data nor does it collect it.
